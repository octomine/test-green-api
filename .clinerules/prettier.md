## Форматирование (Prettier)

### Конфиг

Prettier настроен в `.prettierrc.json`:
- `semi: true` — точки с запятой обязательны.
- `singleQuote: true` — одинарные кавычки для строк, импортов, JSX-атрибутов.
- `trailingComma: "all"` — висячие запятые в объектах, массивах, аргументах, импортах.
- `printWidth: 100` — перенос строк после 100 символов.
- `tabWidth: 2` — отступ 2 пробела.
- `arrowParens: "always"` — `(x) => x`, не `x => x`.
- `endOfLine: "lf"` — Unix-переносы.
- `prettier-plugin-tailwindcss` — сортирует Tailwind-классы в `className`.

### Правила для кода

- **Всегда** писать код в стиле Prettier — не «как получится».
- **Одинарные кавычки** везде: `import { X } from './x';`, `const s = 'text';`, `<div className='...'>` → нет, JSX-атрибуты тоже в одинарных: `<div className='...'>` неверно, верно `<div className="...">`. **Уточнение:** Prettier для JSX-атрибутов оставляет двойные кавычки (это стандарт JSX). Для строк в TS/JS — одинарные.
- **Точка с запятой** в конце statement.
- **Висячие запятые** в многострочных структурах:
  ```ts
  const obj = {
    a: 1,
    b: 2,   // ← запятая
  };
  ```
- **Не выравнивать вручную** — Prettier сам расставит отступы.
- **Не использовать `// prettier-ignore`** без веской причины. Если нужно — объяснить в комментарии рядом.

### Порядок Tailwind-классов

- Плагин `prettier-plugin-tailwindcss` **автоматически** сортирует классы в `className`.
- **Не сортировать классы вручную** — Prettier сделает это при форматировании.
- Порядок: layout → spacing → sizing → typography → background → border → effects → states (`hover:`, `focus:`) → responsive (`sm:`, `md:`).
- Если пишешь классы в новом компоненте в «логичном» порядке — не переживай, `pnpm format` приведёт к правильному.

### Что НЕ форматируется

- `.clinerules/*.md` — исключено через `.prettierignore`.
- `pnpm-lock.yaml`, `dist`, `node_modules`.
- Markdown-файлы (кроме README, если явно не попросят).

### Команды

- `pnpm format` — отформатировать весь проект.
- `pnpm format:check` — проверить без изменений (для CI).
- VS Code: `editor.formatOnSave: true` — форматирует при сохранении.

### Чего НЕ делать

- Не менять `.prettierrc.json` без явной просьбы.
- Не добавлять в `.prettierignore` файлы без причины.
- Не использовать двойные кавычки в TS/JS (кроме JSX-атрибутов и строк, содержащих одинарную кавычку).
- Не выравнивать отступы «вручную» — Prettier перезапишет.
